title: Perl JSON::XS 披露 7 个解析与序列化漏洞
summary: CPANSec 披露 JSON::XS 的 7 个漏洞，均已在 4.05 修复。畸形 JSON 可能耗尽内存或调用栈，部分增量解析和带标签的序列化路径存在内存访问错误。请更新解析或编码不可信数据的服务。
splash: 使用 4.05 之前 JSON::XS 的 Perl 应用。实际风险取决于是否使用增量解析、是否接收畸形输入或处理带标签的值。
wipe: 将 JSON::XS 升级至 4.05 或确认包含修复的厂商回移植版本，重新部署 Perl 工作进程并核实生产环境加载的模块。
cves:
  - name: 增量解析可突破 max_size
    description: 在 4.05 之前，NUL 字节可导致 incr_parse 缓冲的增量输入超过配置的大小上限。
  - name: 对象缺失冒号时发生内存泄漏
    description: 在 4.05 之前，解析器拒绝缺少冒号的对象时，已解码键占用的内存可能未释放。
  - name: 带标签的数据可耗尽调用栈
    description: 在 4.05 之前，启用 allow_tags 时，解码深度嵌套的带标签值可耗尽调用栈。
  - name: 畸形长字符串触发内存泄漏
    description: 在 4.05 之前，解析器拒绝畸形的长字符串时，已解码部分占用的内存可能未释放。
  - name: 增量跳过破坏缓冲区长度
    description: 在 4.0_00 至 4.05 之前，incr_skip 在处理顶层数字后可能从缓冲区末尾之外移除字节。
  - name: 堆缓冲区越界写入一个字节
    description: 在 3.04 至 4.05 之前，增量解析期间追加单字节数据块可向堆缓冲区末尾外写入一个字节。
  - name: 带标签的序列化读取已释放的栈内存
    description: 在 3.0 至 4.05 之前，启用 allow_tags 后，如果序列化 FREEZE 方法结果导致 Perl 栈增长，可能读取已释放的栈内存。

不同漏洞由不同输入路径触发。多项涉及增量解码器，另外几项涉及对象或字符串解析错误。调用栈耗尽和读取已释放内存依赖标签模式，后者发生在编码 FREEZE 结果时。应优先排查解析不可信 JSON 的服务，以及使用带标签序列化的应用。

CPANSec 指出可能发生内存耗尽、无响应、崩溃或无效内存访问。公告未报告生产环境中的利用。准备升级期间可限制请求大小并关闭不需要的可选功能。
