title: Nomad 修复三处隔离缺陷，包括从工作负载影响宿主机的符号链接攻击
summary: HashiCorp 修复跨命名空间泄露及两条工作负载影响宿主机的符号链接路径。宿主机影响取决于作业权限、驱动或迁移配置及客户端代理权限。社区版升级至 2.1.0；企业版升级至 2.1.0、1.11.12 或 1.10.18。
splash: 影响 Nomad 至 2.0.7；攻击需要相关 ACL 读取或作业权限，以及对应路径的配置
wipe: 社区版升至 2.1.0；企业版升至 2.1.0、1.11.12 或 1.10.18，并核对客户端代理
inTheWildNote: 厂商公告未报告真实攻击。
cves:
- name: 跨命名空间读取授权绕过
  description: 在一个命名空间中具有相关读取能力的令牌可泄露其他命名空间的对象；单命名空间集群不受影响，不会因此获得跨命名空间写权限。
- name: 载荷及执行器日志写入跟随符号链接
  description: 工作负载在 allocation 内植入符号链接后，可将写入重定向为客户端代理权限。dispatch 载荷路径需提交并派发作业的权限；Linux exec/java 执行器日志路径需提交作业权限。代理以 root 运行时，可能导致宿主机 root 代码执行。
- name: Allocation 数据迁移跟随符号链接
  description: 攻击者需有提交及更新作业权限，利用 sticky ephemeral disk 在同一客户端复用数据，通过植入符号链接将权限及所有权变更重定向到宿主机目录。没有复用前一 allocation 数据的部署不暴露于此迁移路径。

这是同一批 Nomad 版本修复的三个不同漏洞，不能描述为所有集群均可被未授权接管。命名空间读取涉及 ACL；宿主机影响需要恶意工作负载及特定写入或数据复用路径。root 级影响还取决于客户端代理权限及可写宿主机目标。主流调度器存在有明确说明的隔离失效，因此评为 L3；来源未提供受害者数量或在野利用声明。
