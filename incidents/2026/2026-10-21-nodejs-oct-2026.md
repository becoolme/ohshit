A routine-looking security release with a few nasty pieces. The headline item is an **out-of-bounds write
in the Brotli decoder** (CVE-2026-111497). Anything that decompresses untrusted Brotli data, such as HTTP
bodies, uploads or proxied responses, should treat this as a remote code execution risk.

Two separate bugs (CVE-2026-105483 and CVE-2026-106069) let unusual IP spellings pass **TLS hostname
verification**. That is the check that makes sure the certificate actually belongs to the server you meant
to reach.

The same release ships a `ca-cert` update that **rejects TLS chains containing the compromised eMudhra keys**.
See the [eMudhra incident](/incidents/emudhra-ca/). Already-resumed TLS sessions are not re-checked, so
restart services after upgrading.

We grade it **L4**. It is a core runtime with a remotely reachable memory bug, but there is no
exploitation in the wild yet.

**Update, October 23:** Imperva’s October 22 demonstration reaches RCE through fetched responses and configured request parsers on an official Linux arm64 build. This is laboratory evidence, not a confirmed attack. Other architectures and release lines were not validated by that demonstration. The fixed versions and L4 assessment remain unchanged.

**Update, October 24 — the same Brotli flaw beyond Node.js:** These products embed the vulnerable decoder too. Exposure still requires decoding attacker-controlled data. Python HTTP clients can enable Brotli automatically when an optional decoder is installed; Envoy and Istio require configured Brotli decompression. The Node checker above covers only Node.js, not these separate packages.

| Debian 13 (trixie) brotli package | 1.1.0-2+deb13u1; distribution backports have different version numbers |

cdxgen's advisory covers scanning an untrusted repository that points to an external podspec, and unauthenticated Brotli request decoding at `/sbom` in server mode. Its 12.8.8 binaries still bundled Node.js 24.18.0 despite the intended fix. npm installs use the host runtime instead. Updating host Node alone cannot fix a bundled executable or image. This expands affected-product guidance, not the demonstrated exploit scope: Imperva's lab result remains limited to its tested Node build, and no real-world exploitation is established by these downstream advisories.
