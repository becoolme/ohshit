Cyber Security Cloud 称，外部线索表明一项员工凭据泄露。公司于 11 月 5 日审阅可取得的 GitHub 日志，发现此前发生过可疑访问，怀疑第三方使用了该凭据。日志无法覆盖凭据的整个有效期。公司正在调查泄露路径，尚未公布受影响记录数或人数。部分客户的企业名称、姓名、电子邮件地址，以及服务使用中的通信相关信息可能被查看或获取。

厂商已撤销该凭据，核查并更改存放在 GitHub 的其他服务凭据，调整相关访问权限，隔离有关开发设备并暂停有关账户。公司称尚未确认服务遭未授权操作、发生二次损害，或服务交付和安全功能受到影响。随着范围得到确认，公司将联系客户，并与委托其处理数据的客户协调通知。
