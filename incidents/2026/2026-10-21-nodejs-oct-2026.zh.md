cves:
  - name: Brotli 解码器越界写入
    description: 解压攻击者可控的 Brotli 数据时可能发生越界写入，进而可能导致代码执行。
    plain: 有人往马桶里冲了块砖，管子直接在你机房里爆了。
  - name: dns.resolve 遇到 NUL 就截断
    description: 含 NUL 字节的主机名会被截短，你校验的名字和实际解析的名字不是同一个。
  - name: 全角数字 IP 绕过主机名校验
    description: 用全角数字写的 IP 地址可以通过 TLS 主机名校验。仅影响 24.x 和 26.x。
  - name: 宽松 IP 解析绕过主机名校验
    description: 能被宽松解析成 IP 地址的主机名可以溜过 TLS 主机名校验。三条版本线都受影响。
  - name: keep-alive 提前收到响应
    description: keep-alive 套接字可能会处理一个在请求发出之前就已写入的响应。影响 22.x、24.x 和 26.x。
  - name: 非规范 IPv4 的证书校验问题
    description: DNS SAN 可以借助非规范写法的 IPv4 主机名为 IP 端点做身份认证。影响 22.x、24.x 和 26.x。
  - name: 启动快照导致随机数重复
    description: 启动快照和 SEA 会把 randomUUID、randomInt 的熵缓存一并保存下来，导致不同进程生成重复的值。影响 22.x、24.x 和 26.x。
  - name: 返回无效的 ZIP 头部前缀
    description: ZipFile 在头部校验失败后仍可能返回攻击者可控的前缀字节。影响 26.x。
  - name: 文件系统通配符权限授予过度
    description: 通配符的基数树（radix）查找可能授予过多的文件系统权限。10 月公告列出 26.x，11 月公告还列出 22.x 和 24.x。
  - name: realpathSync 绕过权限模型
    description: fs.realpathSync 可以绕过权限模型（Permission Model）。影响 22.x、24.x 和 26.x。
  - name: Go Brotli 畸形数据 panic 或无限循环公告
    description: "维护者现将 1.2.7 以前的影响列为 panic 或无限循环拒绝服务。报告者在 1.2.6 复现两者，触发流只提供私下分享，未公开；未确立 Go RCE。"

看着像一次例行安全更新，里面却夹着几个狠角色。头号问题是 **Brotli 解码器的越界写入**（CVE-2026-111497）。凡是会解压不可信 Brotli 数据的地方，比如 HTTP 请求体、上传文件或代理转发的响应，都应该按远程代码执行风险来对待。

另有两个互不相干的漏洞（CVE-2026-105483 和 CVE-2026-106069）能让一些不寻常的 IP 写法通过 **TLS 主机名校验**。这项校验的作用，就是确认证书确实属于你要连的那台服务器。

同一批发版还带了一个 `ca-cert` 更新，**会拒绝包含已失陷 eMudhra 密钥的 TLS 证书链**，详见 [eMudhra 事件](/zh/incidents/emudhra-ca/)。已经恢复的 TLS 会话不会重新校验，所以升级后要重启服务。

我们定为 **L4**：核心运行时存在能远程触达的内存漏洞，CISA 现已确认底层 Brotli CVE 遭利用，但没有说明遭攻击的具体下游产品。

**10月23日更新：** Imperva 在 10月22日的演示中，通过获取的响应及已配置的请求解析器，在官方 Linux arm64 构建上实现 RCE。这是实验室证据，不是确认的攻击。演示没有验证其他架构或版本线。修复版本和 L4 评级不变。

**10月24日更新——Node.js 之外的同一 Brotli 漏洞：** 下列产品也内置了受影响的解码器。暴露仍需要解码攻击者可控的数据。Python HTTP 客户端在安装可选解码器后可能自动启用 Brotli；Envoy 和 Istio 需要配置 Brotli 解压。上方 Node 检查器仅覆盖 Node.js，不能检查这些独立的软件包。
