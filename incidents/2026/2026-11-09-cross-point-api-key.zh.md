I’LL 称，攻击者利用一家客户企业泄露的有效 API 密钥，通过会员信息 API 获取了会员资料。厂商将未经授权访问归因于凭据滥用，表示没有直接侵入数据库、篡改数据或利用软件漏洞。截至公告发布，厂商尚未发现其他客户的资料泄露痕迹。受影响企业、会员记录数量及密钥泄露方式仍未公布。

被获取的资料包括姓名、出生日期、性别、邮寄及联系资料、会员编号与等级、积分余额、实体店会员卡号、网店会员 ID，以及消费总额、购买次数和首次或末次购买日期等统计。厂商称受影响系统没有保存支付卡资料或登录密码。全产品密钥轮换涉及所有客户，已确认被获取资料的范围涉及一家客户企业。
