Microsoft tracks Storm-3358 as a financially motivated intrusion cluster based in Cambodia. It began targeting financial organizations in October 2026, primarily in Southeast Asia, with a smaller set of large financial organizations elsewhere. Microsoft observed ARTEX operating alongside conventional tools. The attackers scanned public-facing systems, exploited flaws such as anonymous file upload and server-side request forgery (SSRF), and deployed WISP, vshell and AdaptixC2 for persistence and lateral movement. An exploitable web function is the prerequisite for those entry paths. Actual impact depends on what the service can execute or reach.

Microsoft also describes web shells, abuse of compromised cloud identities and data exfiltration across recent ARTEX attacks more broadly. Microsoft gives no campaign-specific confirmation of what data Storm-3358 took. Microsoft did not disclose victim names, a confirmed victim count, loss totals, affected product versions or a CVE. The rating reflects observed exploitation and remote-access tool deployment. The shared use of ARTEX does not establish a link to the [ConnectWise cloud backup incident](/incidents/connectwise-cloud-backup/) or [the iOS signing campaigns](/incidents/artex-signing-campaigns/).
