两项漏洞均影响兼容 SQL Server 的 TDS 接口。AWS 列出的上游 Babelfish 受影响范围为 1.0–1.5、2.1–2.15、3.1–3.12、4.0–4.8 和 5.1–5.4。Aurora 有单独的受影响构建及回移补丁。请查阅 AWS 公告的完整范围，为当前引擎选择受支持的升级路径。
