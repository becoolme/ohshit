初始化竞态 CVE-2026-125423 需要创建仓库与推送的权限、使用默认 README 自动初始化，以及允许构造的符号链接指向可写 Git 钩子的服务端目录布局。利用成功后，命令以运行 Gitea 服务的操作系统账号权限执行。维护者在 28.3.0、28.2.0、1.27.1 和 1.25.5 上复现了问题。仅关闭用户自定义 Git 钩子无法堵住这条路径。

仓库搜索泄露漏洞 CVE-2026-123006 影响 28.0.0 至 28.3.0。访问者需登录，目标仓库需可见且具有提交状态。暴露的密码材料可用于离线猜测。公告未说明是否有账号成为攻击目标。

28.4.0 的二进制程序还采用 Go 1.27.4，包含已在 [Go 11 月安全公告](/zh/incidents/go-november-security/) 中记录的 HTTP 服务修复。部分 Gitea 修复此前已发布。RubyGems 索引修复最早随 28.3.0 发布，议题和拉取请求授权问题的部分修复已随 28.2.0 和 28.3.0 发布。升级到本次完整版本可获得剩余修复。
