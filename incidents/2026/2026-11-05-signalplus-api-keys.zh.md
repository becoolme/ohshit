币安 11 月 5 日通知确认因安全原因撤销第三方集成凭据，仍将 SignalPlus 的报告描述为**潜在**安全问题。没有确认密钥被盗、未授权交易、资料窃取、受害人数或金额。币安所称自身系统未受影响，是针对此次通知的厂商说法，不是推翻独立的 10 月 29 日钱包事件。

风险边界是交给 SignalPlus 的 API 连接，不是全部币安账户。撤销的凭据无法继续认证新 API 请求，但用户仍须直接检查账户状态。具体的整项平台集成密钥撤销及用户须立即处置的交易所凭据，支持将此列为需要关注的事件；实际利用仍未确认。

CZ 另提及 Deribit，但本轮未独立核实其完整原始客户通知。SignalPlus 的完整技术说明、受影响凭据权限、实际利用及重开条件仍待确认。没有证据确立与[币安 10 月 29 日事件](/zh/incidents/binance-wallet-investigation/)的原因或攻击者关联。
