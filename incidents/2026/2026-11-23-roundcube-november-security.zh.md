本批次涉及两条 Sieve 注入路径（比较器名称及 body/address/envelope 字段）、两项 CSS 隔离绕过、SVG 远程内容拦截绕过、CSS 代理响应泄露、PHP 8.4 以下版本中的命名空间前缀属性绕过、TNEF 解码器拒绝服务、密码插件 XIMSS XML 注入，以及已配置 TLS 但服务器未返回能力信息时的 IMAP/SMTP/ManageSieve 不安全回退。此外，再次修复 ATD 拼写检查请求注入及将不安全的 PDF/PostScript/SVG 内容传给 ImageMagick 的问题；此前的修复不能代替本次更新。

是否暴露取决于相应功能、后端或内容处理路径，不代表所有部署都暴露全部问题。公告未提供 CVE 编号或数值评分。主流 Webmail 应用的安全边界受到影响，支持定为 L3；尚无已确立的在野利用结论。
